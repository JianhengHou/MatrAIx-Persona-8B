# Entscheidung über einen Asylantrag

Es ist Anfang 2016, während der europäischen Asylkrise.

Sie sehen fünf Paare. Jedes Paar zeigt zwei Personen, die in Ihrem Land Asyl beantragt haben, nebeneinander, so wie sie Ihnen vorgelegt wurden.

Wenn Sie sich für jedes Paar entscheiden müssten: Welchem der beiden Antragsteller soll Asyl gewährt werden?

## So antworten Sie

- Beantworten Sie jedes Paar.
- Verwenden Sie die angegebenen Optionsnummern.
